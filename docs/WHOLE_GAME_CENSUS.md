## 2. Method

**Static reachability** (`static`). Functions: `docs/FUNCTIONS.csv` (boot) and `overlay_match.true_functions` per overlay (runtime address = link vram + 0x40). Edges: direct calls, tail jumps and branches into another function, and address constants built in code (a high/low pair whose value is a function entry). Roots: the entry point and every data word equal to a function entry (boot data outside code bodies, each overlay's header and data sections). A boot data word inside the overlay arena is credited to every overlay with an entry at that address (an over-approximation: it can only add reachable functions, never hide one).

Validation: (1) the three AREA21 functions an earlier overview called "no static reference" (00824CF0, 00824FE0, 00825B00) are found, through boot spawn data words; the first version of the detector missed them (it scanned only the overlay's own data), which is why the boot data scan covers every word outside a code body. (2) All 1,873 boot functions the per-level route censuses (`route_census.py`, 37 passes) saw executing are statically reachable; the first version missed two (001C2690, reached by a branch from another function, and 001C2FF0, an interior piece of 001C2770), which added branch edges. (3) Every function the replays below executed is statically reachable (16 exceptions).

**Dynamic coverage** (`dynamic`). Each kept recording (Claude's guided takes g01..g80 and the user's takes, read only) is replayed hidden in the fork from its own start state with inline count probes on every function entry (one session holds all of them), stopped every 600 vsyncs to read the hit list and the resident overlay id, so an overlay hit is credited to the overlay that was loaded. The run lock is released between takes. Each replay's end machine (hashes and EE cycle) is compared with the take's end.json.

**Port coverage** (`port`). Mechanical, from `src/` and the census ledgers: *translated* = a function defined in `src/` whose name ends in the address (the rule of the port's `tools/level_readiness.py`, overlay area from the symbol or file name, plus its aliases); *bound* = the address as a constant in code (dispatch cases, entry tables, binding tables); *ledger* = the latest status in FIRST/SECOND/THIRD_LEVEL_CENSUS and WHOLE_GAME_LEDGER (live, verified-unbound, unverified count as ported; stand-in and boundary as (C); a WHOLE_GAME_LEDGER `missing` row overrides a mechanical *bound* (a hook's callee address the live host does not serve), and its `unreachable` row (a data word that is not a pointer) makes the row (D)). An address only cited in comments or strings does not count. Limits: *translated* does not prove the translation is bound in every area (the port's dispatch is code, not a table, so it cannot print its bound set); a translation named without its address and absent from the ledgers is missed (the row then shows here as unported).

**(C) rules.** The platform boundaries of FIRST_LEVEL_CENSUS section 4 applied to the whole ELF: 00100000..00130000 SDK / kernel / libc / libpad / libcdvd / libmc / libmpeg / EE sound library: host services; 001CB5C0..001DB000 GS/VIF packet build, texture upload, display-object registry: the native renderer; 001E7050..001E7E00 stream archive reads: host file reads of locally exported assets; 001FA0D0..001FE000 EE sound driver internals and music streams: em_sfx / em_audio; 001FE070..001FF000 CD stream service: host file reads; 001FF080..002009E0 module loader and disc reads: em_module_loader + host reads; 001F9820..001F9D00 stream / voice IOP service tick: em_stream_live and the host audio thread; 00203350..00207000 IOP services, heap, MPEG glue: host OS / allocator / movie player; 00207060..00208B00 2D GS draw layer: em_gfx 2D layer; 0022E630..0022FD00 SDK GS setup: the native renderer. ## 8. Re-running

Decomp root, native arm64 macOS (the fork runs x86_64 under Rosetta, hidden):

```
.venv/bin/python tools/game_census.py static     # ~1 s
.venv/bin/python tools/game_census.py validate
.venv/bin/python tools/game_census.py dynamic --takes all   # resumable, one JSON per take; ~100 vsyncs/s
.venv/bin/python tools/game_census.py port       # reads ../extermination-port
.venv/bin/python tools/game_census.py report
.venv/bin/python tools/game_census.py doc --out ../extermination-port/docs/WHOLE_GAME_CENSUS.md
```

After a port change only `port`, `report` and `doc` need re-running; `dynamic` only when a new recording is kept (`--takes gNN`).
