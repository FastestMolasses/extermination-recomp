# AREA17's overlay owners (lane PORT-A17A18)

Lane PORT-A17A18, 2026-11-17, branch `a17a18`. AREA17 (area byte 0x11,
overlay id 0x0E, `OVERLAY/AREA17.BIN`) is the power reactor's roof: the
arrival from AREA14, Roger's fight (00133E30, `em_area17_creature`, lane
BOOT2), the item exchange (item 0x28 for 0x2B) and the cable ride to AREA11
entry 3. This lane translated every overlay function of AREA17 but the init
(em_area01_state's, `make test-second-half-state-reference`) and the entry
pad, each proven by an original-instruction oracle. Since lane PORT-LIVE2 AREA17
loads live from a guided-run card (section "Live"); no frame is row-checked yet.

Ground truth: the decomp's C under `src/overlays/AREA17/` (lane OVLC,
decomp `docs/AREA17_OVERLAY.md`): 22 functions byte-identical and 0x825560
NEARMISS (99.41%; the oracle runs the original words, so it decides).
Overlay addresses below are runtime addresses (the decomp's link names are
0x40 lower).

## The oracle

`make test-area17-overlay-reference` (`tools/test_area17_overlay_reference.py`),
the harness of `tools/test_level14_port_reference.py` configured as
test_area14_overlay_reference configures it. The ORIGINAL overlay code runs
from the user's `extract/OVERLAY/AREA17.BIN`, resident in two end states of
Claude's guided run (decomp `build/guided_play/g46_area17_ramp` and
`g47_area17_roger`, `end.p2s`; their eeMemory and scratchpad are extracted
once into ignored `build/area17_overlay/states/` with the decomp's venv). The
loader checks the resident overlay's header and text against the file and the
boot text against the pinned ELF. Cases: the 24 live AREA17 owner nodes of
the two states as recorded, and designed states in zero RAM (every state and
step, the boundary counts, the float ramps at and one ulp around their
limits, scribbling callees, a seeded random sample). Callees are hooks with
scripted results except the pure helpers (001026A0, 001028D0, 00102738,
00102918, 00102948, 001029C0, 00102B08, 0011DE90, 0011E2A8, 0011E748,
001B1470), which run as original code. Compared per case: every call and
its arguments, memory at every call, the memory accesses between calls one
for one in order, memory after the last store, a poisoned re-run; then the
coverage of every reachable original word, the callee inventory and the
fail-stop contract of every hook.

Result: 1304 cases in the quick run (about 4 s), 1766 with `EM_TEST_FULL=1`
(passed once, 15 s); 2129 of 2129 reachable words of the 22 functions, no
dead word. A mutation of 0x825560's range bound (50.0 -> 51.0) fails 39
cases.

What the oracle does not show: the live nodes of the two states cover [30],
[31], [33], [34], [36]..[42] and 0x8260C0, not the breakables [5]..[8]
(not live in either state), 0x8239D0, 0x8251B0 or the effect objects; those run on
designed states only. No capture of a frame in AREA17 compared the port's
run with the original's.
